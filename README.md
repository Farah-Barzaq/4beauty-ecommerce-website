# 💄 4Beauty – E-commerce Website

A modern and responsive front-end e-commerce website for beauty and cosmetics products. The project focuses on delivering an attractive shopping experience with a clean UI, responsive design, and interactive features using pure front-end technologies.

## 🌐 Live Demo

https://farah-barzaq.github.io/4beauty-ecommerce-website/

## 📂 GitHub Repository

https://github.com/Farah-Barzaq/4beauty-ecommerce-website

## ✨ Features

- Responsive design for all screen sizes
- Modern and clean UI
- Product listing
- Product search
- Shopping cart
- Local Storage for saving user data
- User authentication interface
- Category filtering
- Smooth navigation
- Attractive animations and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- Font Awesome


## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/Farah-Barzaq/4beauty-ecommerce-website.git
```

2. Open the project folder.

3. Run `index.html` in your browser or use Live Server in VS Code.
